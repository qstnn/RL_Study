# R5A Guided v2：提前后腿展开，平滑落地交接

本补丁安装到已经运行过 `r5a_guided_v1.sh` 的离线 R5A 项目。新增独立 v2，旧 v1/v6、模型和训练结果保留；无需 Git 或网络。

## 本次修复

目标电脑原教师在1.034秒发生左前小腿与左后大腿自碰，非轮接触力约2561N，因此未进入BC/PPO。源码和教师的44项实现哈希一致，角动量检查通过；首次触地合格不代表后续恢复成功。

从返回的1.000秒空中状态继续做成对CPU诊断，旧控制在1.033秒重现同部位碰撞，仅平滑交接仍失败。后腿展开起点从约343.04°提前到331.44°，并平滑过渡到落地控制后，诊断窗口内碰撞消失。此处状态重建仅用于诊断，未进入交付教师、示范或PPO。

三个交付候选均从原始站姿完整跑满6秒：旋转353.17°、首次触地倾角4.61°、轴偏差18.82°；末段连续站稳约3.67–3.95秒。候选仅交接时间不同，顺序为80、40、120毫秒。原物理、电机限值、奖励、动作范围、碰撞及成功判定保持。

本机验证使用CPU，目标GPU必须现场复核。80毫秒候选的触地支撑峰值约168倍体重，高于旧CPU教师约79倍；本次消除自碰不代表冲击改善，也不构成实机动作验收。3000步模仿后的学生自主基线约355.01°，但1.46秒落地恢复失败，尚未学会完整动作；后续PPO仍需改善恢复，不能用教师成功代替学生成功。

## 在另一台电脑安装并训练

把补丁ZIP和`.sha256`放入原项目根目录，即能看到`r6.sh`、`r5a_guided_v1.sh`的目录，然后执行：

```bash
sha256sum -c lighthw-r5a-teacher-guided-v2-landing-patch-20261022.zip.sha256
python3 -m zipfile -e lighthw-r5a-teacher-guided-v2-landing-patch-20261022.zip .
python3 lighthw-r5a-teacher-guided-v2-landing-patch-20261022/install.py .
bash r5a_guided_v2.sh check
bash r5a_guided_v2.sh train
```

安装器先校验基础文件与全部载荷；遇到不同内容的已有文件会在写入前拒绝。无需删除旧的`offline_sessions`、`usb_review`或旧准备标记。v2使用独立准备标记与输出目录。

若原环境需要自定义路径，沿用：

```bash
R5A_PYTHON=/绝对路径/lab/bin/python R5A_ISAAC_SIM=/绝对路径/isaac-sim bash r5a_guided_v2.sh train
```

`train`自动完成：按顺序尝试候选 → 同一候选在目标设备两次完整回放通过 → 600帧示范与3000步监督初始化 → 一次学生自主基线 → 连续3000次更新尝试（前20次只预热Critic）→ 末尾统一评估与精简USB导出。无须再输入其他启动命令。

若一个候选行为不通过，会尝试下一个；程序异常不会被当作成功。三个候选都未通过时停止并输出诊断ZIP。新增`[TEACHER FAILURE]`列出首个失败时刻、接触部位和力，便于直接定位。不会绕过碰撞或完整成功条件启动PPO。

正式PPO由学生网络执行，示范只用于初始化和辅助监督；没有状态注入、教师强制接管、环境噪声或物理随机化。中途每200次只保存，训练结束后统一评估，不分段回收。

## 观察与回收

只做准备而暂不启动PPO：`bash r5a_guided_v2.sh prepare`。

回放：`bash r5a_guided_v2.sh play --checkpoint /完整路径/selected.pt`，保留自由视角与原本机外观。

后续续训仅接受v2检查点及对应示范：`bash r5a_guided_v2.sh train --checkpoint /完整路径/final.pt --updates 1000`。本次v1尚未开始PPO，不需要迁移优化器或旧检查点。

完成或失败后只取回打印的`[USB REVIEW ZIP]`文件及同名`.sha256`。保留选中模型、必要曲线、准备过程、录像和逐毫秒轨迹；不必拷贝整个项目。Ctrl+C会尝试导出诊断包；未完成评估不标记成功。
