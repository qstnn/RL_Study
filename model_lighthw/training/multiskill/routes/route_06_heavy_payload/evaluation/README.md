# R6固定载荷持载筛查

默认3个seed（43/44/45）、每seed 4次独立reset，每次20秒，2秒后统计持载。
每次实际reset有小幅姿态随机化。逐项记录完整/终止/非有限与初始状态，不用自动重置补足失败窗口。

| 指标 | 通过门槛 |
|---|---:|
| 倾角P95 / 最大 | ≤5° / ≤15° |
| 平速P95 | ≤0.05m/s |
| 偏航角速度P95 | ≤0.05rad/s |
| 站高误差P95 | ≤0.04m |
| 四轮同时>5N占比 | ≥95% |
| 关节达到模型力矩限幅99%的平均占比 | ≤5% |
| 持载窗相对起点最大水平位移 | ≤0.05m |
| 非轮接触 | 0 |
| 完整性 | 1000步，无提前终止或NaN/Inf |

代码协议在`scripts/metrics.py`，门槛在`payload_spec.py`；这套初始工程筛查门槛不代表硬件规范。
晋级参考总体成功率≥95%，但仍要检查轻载保留、失败和实际曲线。
日志50Hz，不能声称测得1kHz峰值。最终验收始终`not_evaluated`；热/结构与载荷碰撞不在当前模型内。
