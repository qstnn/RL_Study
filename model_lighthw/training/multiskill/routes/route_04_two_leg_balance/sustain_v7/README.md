## 行为与奖励

入场沿用真实四轮稳定0.5秒、最早1秒起身、3秒入场失败。局部3秒起身参考完成后，目标持续保持；连续2秒全门合格只记捕获。从真实入场/开始起身事件起计8秒仍未捕获，作为任务失败结束。之后没有7秒/12秒自动返回：只有`env.request_return(env_ids)`触发返回，参考时钟从命令时刻开始。

保持门沿用两后轮承载、两前轮卸载且净空≥3cm、COM支撑线≤6cm、姿态误差≤12°、速度≤0.12m/s、角速度≤0.25rad/s，以及1kHz实际高频门。允许慢漂移累计，取消相对出生点1.2m成本与1.5m失败门；400m地面的实际边界留2m余量，边界截断单独记录，不能记成完成观察。没有瞬移或中途重置滤波器。

| 变化 | 已实现设置 |
|---|---|
| 持续平衡 | 权重12，每个控制周期累计20个1ms样本的合格时间；周期中1ms失稳也会减少收益 |
| 短时事件奖 | `hold_once / success_once / missed_hold`均为0；捕获或观察结束不加大奖 |
| 返回/恢复 | 仅明确返回命令后生效，站立期间主动回到四轮不能拿恢复分 |
| 时间/位移成本 | 时间成本仅起身阶段生效，保持阶段为0；原点位移成本为0 |
| 连续姿态/COM/卸载/净空 | 保留v6初始权重，后续按实际分项收益和行为调整 |
| 平滑与速度 | 实际振动−0.5，超0.12m/s成本−2，动作一阶/二阶差分−0.05/−0.25 |

捕获后首次支撑、姿态、速度或实际振动中断，永久记录`first_break_time / break_reason`。训练中重新站稳仍有逐步收益，但不能恢复本次“全程不中断”的通过资格。10/30/60/300秒观察均指捕获后**额外**持续合格时长，不包含起身或前面的2秒。
