## 阶段信息结论

原单帧61维由角速度、重力方向、腿位置、关节速度、上一动作、支撑模式、目标重力、任务参考阶段和站立请求组成，堆叠五帧共305维，历史跨度80ms。任务参考阶段与教师实际捕获阶段不同。

现有7726训练帧，以及6份成功/失败档案的9651个有效控制帧中，`实际俯仰<=−5°且站立有效、非入场`与教师触发锁存状态均无不一致。这只支持在已见轨迹中区分触发前后；不能证明80ms历史充分表达0.8秒混合进度、所有闭环反馈或新状态下的触发记忆。[检查明细](validation/phase_information.json)。

## 单因素定义

两组均为共享305→256→256→128 ELU主干、两个128→16输出头，共181152个参数。主干和两头全部显式从学生02复制；两头初始相同，初始输出与原策略相同。

| 项目 | uniform对照 | observed实验 |
|---|---|---|
| 两个输出头组合 | 固定各0.5平均 | 根据原观测中的实际俯仰选择起身头/捕获头 |
| 数据 | 同一7726帧文件 | 同左 |
| 训练 | 6000次Adam更新、batch512、四阶段各128 | 同左 |
| 学习率 | 3e−4余弦降至3e−5 | 同左 |
| 初始权重、采样顺序、网络容量、物理/奖励 | 完全一致并核对 | 同左 |

不直接将容量翻倍的两个独立MLP与原模型比较。两组都有相同双头；唯一干预是输出组合/梯度路由。采样SHA一致，初始各张量逐值相等。路由是原305维输入的无状态函数，不读取教师、COM、接触、回合年龄或观察截止时间；未加入教师查询动作标签。触发后混合进度仍由网络拟合，尚未显式加入记忆。

## 复现入口

以下仅用于有限对照复现，当前结果无需原样重跑。输出目录必须全新。默认评估三seed；`--seeds 43`用于准入前两槽筛查。

```bash
cd /home/user/RL_lab/rl_training/model_lighthw/training/multiskill/routes/route_04_two_leg_balance/sustain_v7/student_phase_v3
bash phase.sh check
bash phase.sh train --routing uniform --output runs/new_uniform --device cuda:0
bash phase.sh train --routing observed --output runs/new_observed --device cuda:0
bash phase.sh evaluate --actor runs/new_observed/actor.pt --seeds 43 --output runs/new_screen
bash phase.sh verify runs/new_screen
```

仍需纯学生从四轮初态完成两槽×seed43/44/45捕获后额外10秒，随后通过真实PPO更新/保存/续训与末状态价值短验，才给正式命令。最终目标是自主60秒重复与300秒耐久。稳定段≤0.12m/s慢漂移、真实高频门、无环境噪声随机化、R4b等待及正式训练无自动冻结审查保持。
