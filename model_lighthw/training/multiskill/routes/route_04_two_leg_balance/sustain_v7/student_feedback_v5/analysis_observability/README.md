# R4a 支撑方向状态的可预测性诊断

日期：2026-10-23，Asia/Shanghai。CPU 离线诊断；新增 GPU 仿真、机器人 PPO、动作标签均为 0。所有新增文件只位于本目录；原执行源、快照、7726 帧数据及失败轨迹保持原 SHA。

## 结论

**本体输入包含可用于估计支撑方向 COM gap 与速度的信息，但当前数据和通用回归器不足以证明失败分布上的反馈估计可靠。** 成功来源的 capture 段中，raw305 的 ridge 已能把 gap 估到毫米量级、速度平均误差约 0.01 m/s；加两维捕获记忆没有一致提升。失败 exposed 轨迹在碰撞前的 4.4–5.0 s 已有明显速度误差和方向错误，不能以长稳态占多数的全局平均误差作为准入证据。

这不是“MLP 天生缺少信息”的证明，也不能把诊断回归器错误当成旧 Actor 的内部估计错误。原 Actor 并未显式运行这些估计器。本检查只测试从同一可部署输入预测两个真实物理状态的能力，不评估新策略自主控制成功。

## 输入、标签与拆分

- 输入分别为未改动的 raw305，及 raw305＋2维因果捕获记忆。记忆只由历史原始观测重建：−5°触发锁存和之后40个50Hz控制步的 smoothstep 进度；不使用回合年龄、物理截止、教师特权或失败判据。
- 标签严格采用 `teacher_sustain.py` 正在使用的定义。后轴横向向量 `lateral=RL_xy−RR_xy`，前向 `forward=[lateral_y,−lateral_x]/max(norm,1e−6)`；`gap=dot(COM_xy−rear_midpoint, forward)`，`velocity=dot(COM_vel_xy, forward)`。这是有符号 gap，不能以非负有限线距离代替；速度也是该前向投影，不能以 COM 速度模长代替。
- policy 输入 k 对齐到**上一物理状态 `k×20−1`**。k=0 没有该物理状态，7726 中2帧排除，得到7724个可评分数据帧；绝不以 `[-1]` 误取末帧。其余 source_kind>0 的数据本来就从已执行教师段开始，没有 k=0。
- 四折整份来源 trace 留出，**每份的两个槽位共同留出**。原数据与完整来源轨迹分别计分；同一来源的邻近帧或另一槽不能进入该折训练。四份来源为名义 hybrid、early、late、旧 takeover3200。
- 两组 memory-v4 失败轨迹 zero/exposed 各双槽完全独立列作 OOD。它们不进入训练、归一化、超参数选择或动作监督。
- 每折标准化只拟合训练来源；固定 ridge α=1、标准化5近邻距离加权，以及两层128/64 ELU小 MLP。MLP固定seed42、1500次CPU更新、每个现存阶段64帧平衡抽样。数据动作数组不加载，不生成动作标签，不导出可执行 Actor。
- 所有来源的输入重力、角速度与 `k×20−1` 物理状态逐项对齐；记忆与原数据/失败轨迹核对；NumPy标签与独立Torch同式实现核对通过。

## 留出来源的结果

下表为合并四折的 **capture 段1326帧**。方向错误仅在 `|gap|>5 mm` 或 `|velocity|>0.02 m/s` 的真实非零状态计算；完整 JSON 同时保留 `>1e−6` 的近零敏感结果与分母，避免用近零换向噪声掩盖实际方向错误。

| 输入/方法 | gap MAE / P95 (mm) | 前向速度 MAE / P95 (m/s) | gap / 速度非零方向错误 |
|---|---:|---:|---:|
| raw305 ridge | 1.32 / 8.14 | 0.01065 / 0.08323 | 0 / 0 |
| raw307 ridge | 1.29 / 7.31 | 0.01074 / 0.08985 | 0 / 0 |
| raw305 5NN | 4.45 / 19.55 | 0.01213 / 0.04599 | 0.96% / 0.71% |
| raw307 5NN | 4.09 / 17.60 | 0.01207 / 0.04599 | 0.96% / 0.71% |
| raw305 MLP | 5.17 / 42.62 | 0.00590 / 0.01928 | 0 / 0 |
| raw307 MLP | 4.03 / 25.20 | 0.00636 / 0.03191 | 0.14% / 0 |

把 rise 与 capture 合为过渡段，共1626帧：raw305 ridge 的 gap MAE/P95 为5.68/23.48 mm，速度为0.02644/0.12288 m/s；raw307 MLP 为13.24/41.78 mm和0.01663/0.09024 m/s。它们各有优劣，不能选一个全局数字宣称信息估计已通过。

**整份名义轨迹留出的折特别困难。** early/late/takeover 数据按旧规则排除了学生执行前缀，因此将名义轨迹整个留出后，训练集没有同等覆盖的入场/起身样本。这一折 raw307 ridge 的完整过渡速度 MAE/P95 为0.06527/0.35004 m/s；其他三个完整来源留出折为 MAE 0.00771–0.00996、P95 0.02373–0.03270 m/s。这是明确的分布覆盖缺口，不能解释为简单的记忆输入缺失。

原7724帧中6000帧是 post-capture 长稳态，几乎静止；raw305 ridge 在该段速度 MAE仅0.000545 m/s。该低误差会显著拉低全局均值，所以必须看过渡/capture与失败分布。

## 失败分布：碰撞前已经出现估计错误

用全部7724帧拟合后，直接评分从未参与训练的 v4 失败轨迹。以下为 capture 段：zero190帧、exposed201帧。

| OOD/方法 | gap MAE / P95 (mm) | 前向速度 MAE / P95 (m/s) | 速度非零方向错误 |
|---|---:|---:|---:|
| zero raw307 ridge | 3.73 / 24.31 | 0.03018 / 0.09480 | 0 |
| zero raw307 MLP | 7.28 / 41.53 | 0.02174 / 0.06674 | 0 |
| exposed raw307 ridge | 8.43 / 48.17 | 0.12798 / 0.72447 | 12.69% |
| exposed raw307 MLP | 20.31 / 90.00 | 0.08438 / 0.46728 | 3.55% |

为避免末期已失稳状态主导结论，另固定考察 **[4.4,5.0) s**，每槽30帧；所有帧都早于 exposed 槽0的5.28 s非轮接触和槽1的5.14 s倾倒保护。这里的窗口单位是物理时间，不是教师动作输出后的下一步。

| exposed窗口/方法 | 速度 MAE / P95 (m/s) | 非零方向错误 |
|---|---:|---:|
| 槽0 raw307 ridge | 0.17847 / 0.43126 | 11/29 = 37.93% |
| 槽0 raw307 MLP | 0.15436 / 0.34573 | 7/29 = 24.14% |
| 槽1 raw307 ridge | 0.12762 / 0.30772 | 0/30 |
| 槽1 raw307 MLP | 0.09269 / 0.16271 | 0/30 |

首次参考偏离沿用旧v4报告定义：与名义 hybrid 同物理时刻相比，重力方向差>5°或**相对初始位置的三维COM位移差**>3 cm。独立复算 exposed 槽0在4.348 s、槽1在4.839 s首次偏离。

槽0 ridge/MLP首次显著速度方向错误都在 **4.780 s**：真实前向速度−0.04319 m/s，raw307 ridge估为+0.13091、MLP估为+0.09678 m/s。它比第一次参考偏离晚0.432 s，距实际非轮碰撞仍有约0.50 s。因此：

1. 估计错误发生在有控制意义的碰撞前阶段，不能全部归为落地后异常。
2. 该错误晚于轨迹偏离，不能倒因果断言“估计错误引发了最初偏离”。
3. “方向不错”仍不等于反馈量级可靠：槽1方向无错，速度P95误差仍达0.16271–0.30772 m/s。

`time_windows.json` 另保留3.2–4.4、4.4–4.7、4.7–5.0、5.0以后、首次偏离之前/之后的逐槽统计和每个方向错误的精确时刻、真值/预测值。失败帧与reset后帧不进入拟合或评分。

## 对后续结构设计的意义

原raw305包含重力方向及关节位置；相对后轴的几何gap不依赖世界平移，物理结构计算比用自由回归器在有限成功分布上外推更值得核验。前向COM速度则涉及运动/滚动与接触状态；轮速只有在相应滚动约束有效时才能支持可信的速度估计。本诊断没有证明任意滑移/悬空状态下的全局可观测性，也未验证rolling估计器。

数据支持把下一步定位为：保留已学起身能力、减少previous-action shortcut的依赖、核对有物理结构的gap/速度估计与低维局部反馈，再做实际自主捕获验证；**不支持直接开放PPO**。任何新动作标签仍须来自实际执行且恢复/保持成功的教师，不能把失败轨迹上的影子教师查询当成功示范。本目录没有实施新反馈策略或改变旧验收门。
