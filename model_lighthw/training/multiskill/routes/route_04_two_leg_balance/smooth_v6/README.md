## 新验收与实际振动检测

保持原305维Actor、88维Critic、16动作、50Hz控制/1kHz物理、固定四轮初态、无观测噪声/随机化；质量、摩擦、48/24Nm限矩、PD及动作映射不变。R4a仅后腿支撑，R4b等待。

- 仍需两后轮各>5N、两前轮各<2N且净空≥3cm、COM支撑线≤6cm、目标姿态误差≤12°、COM总速度≤0.12m/s、角速度≤0.25rad/s，连续保持2秒。
- 稳定保持和终末四轮阶段取消相对阶段起点10cm的累计位移门；终末仍需连续稳定四轮1秒。全回合1.5m空间边界、机身碰撞、高度/倾角及有限值检查保留。
- 稳定保持及终末恢复增加**实际状态**高频门。1kHz采集COM速度、IMU角速度、12腿关节位置、4轮实际速度；二阶Butterworth高通截止5Hz，指数RMS时间常数0.10秒。该滤波只用于评价/奖励，没有改变Actor输出或执行器指令。

| 指标 | 稳定窗口内RMS上限 |
|---|---:|
| COM速度高通分量，三轴向量 | 0.02 m/s |
| 机身角速度高通分量，三轴向量 | 0.05 rad/s |
| 腿关节位置高通分量，最差关节 | 0.2° |
| 轮实际速度高通分量，最差轮 | 0.50 rad/s |

这是本轮明确的工程筛查阈值；高通滤波在5Hz附近平滑过渡，不能声称“所有高频成分绝对为零”。捕获和返回转换过程另行记录；只有同时通过速度、支撑、姿态和高频门的连续稳定窗口才计入2秒/1秒。四条教师轨迹首次达成2秒后至返回前，未记录新的高频越限。不能仅看动作指令平滑，也不能用50Hz观测代替实际关节1kHz检测。

## 奖励调整

原姿态、COM、卸载、支撑、净空、阶段完成和失败项保留。新档案名为`slow_drift_smooth_v6`：

| 修改 | 设置与作用 |
|---|---|
| 取消保持原点惩罚 | 不再以`exp(-(保持漂移/0.1)^2)`压低捕获收益；位移成本只在全回合离初态超过1.2m时提供空间边界缓冲 |
| 慢速死区 | 速度质量使用`max(COM速度−0.12,0)`，允许范围内平移不承担速度成本 |
| 实际振动成本 | 保持/恢复阶段，各RMS除以上表限值后平方、每项截顶4并取均值，权重−0.5；捕获质量同时乘`exp(−该成本)` |
| 超速成本 | 保持/恢复阶段，超过0.12m/s才计分，归一化平方截顶4，权重−2 |
| 指令交替成本 | 保持/恢复阶段，执行动作的二阶差分平方均值，权重−0.25 |
| 原动作变化成本 | 全程一阶差分平方均值，权重由−0.025改为−0.05 |

连续项仍乘控制周期0.02秒，阶段成功事件不乘dt。新增奖励已在真实环境逐步运行，但本轮仅进行监督纠偏，没有PPO学习新奖励的效果证据。
