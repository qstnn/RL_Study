## 为什么增加反馈没有解决捕获偏晚

1. **接管时刻与捕获触发时刻不同。** 三组均到4.54/4.62秒才达到教师−20°触发条件，0.5秒姿态混合到5.04/5.12秒才完成。增益变化第一次改变执行动作是在4.56/4.64秒，无法改变更早的起身路径。要在7秒返回前保持2秒，需要全门稳定最晚在5秒建立。
2. **角速度峰值下降没有转成更早稳定。** 捕获段角速度峰值随0.20→0.25→0.30，槽0为1.932→1.886→1.828rad/s，槽1为2.000→1.933→1.858rad/s；同段COM速度峰值却略增，分别0.800→0.805→0.813、0.797→0.802→0.809m/s。即使仅在分析中去掉全部高频门，保持也分别只有1.678/1.600、1.649/1.578、1.645/1.602秒，仍不足2秒。
3. **腿部高频门最后解除。** 六例全部物理门在约5.32–5.42秒后持续达标，但腿部RMS到约5.67–5.76秒才持续达标。高频表现未随增益单调改善：例如槽1整个4–7秒窗口的轮速度高频RMS峰值由0.493升至0.579/0.630rad/s。该峰值包含捕获瞬态，不表示最终已合格的短稳定段仍超限，也不支持放宽原高频门。

合格短稳定段最高速度为0.0221–0.0480m/s、净位移约0.117–0.832cm。允许慢漂移的条件已满足，主要缺口是建立稳定太晚、持续时间不足。以上与[运行前假设](HYPOTHESES.md)相比：增益足以提前稳定的假设未获支持；反馈晚启用是已记录事实，提前触发能否改善则仍是待验证假设。
