## 本轮定位到的缺口

**主要问题是建立合格稳定段太晚。** 最好的3.2秒接管，槽0到5.666秒、槽1到5.759秒才开始最长连续合格段，随后一直保持到6.999秒；7秒按原时间表进入返回，因而只留下1.334/1.241秒。要在原协议下完成2秒，稳定段需提前到不晚于约5秒，当前还差约0.67–0.76秒。本轮没有延长保持窗或推迟返回来改判成功，也尚未证明若继续保持可以稳定多久。

这两条短稳定段的最大速度仅0.0221/0.0231m/s，净位移约0.117/0.151cm。慢漂移本身不是这一组失败的原因。2.8秒接管反而更晚到6.657/6.688秒才稳定，因此当前三点结果不支持继续一味提前接管。

高频振动进一步推迟了计时：3.2秒组去掉全部高频门后仍只有1.678/1.600秒，依然不足2秒；只去掉腿高频门则为1.536/1.427秒。它是额外限制，但不能单独解释整个缺口，更不能靠放宽高频门解决。

接管瞬间的实际腿位置目标最大跳变为0.0042–0.0384rad；3.2秒组为0.0117/0.0303rad。此记录尚不足以把退化归因于交接冲击，不优先添加未经对照的输出滤波。原strong教师在第三轮访问状态曾4/4完整通过，本轮换成第四轮实际前缀后0/6，说明教师恢复效果依赖具体到达状态，不能复用旧成功结论。

按[实验前假设](HYPOTHESES.md)逐项判断：完整恢复可行的假设在本组六例未获支持；接管时机有影响但并非越早越好；高频是额外瓶颈而非唯一瓶颈；本组原教师未完成原时间窗内的完整任务，但六例无物理失败且出现短稳定段，不能据此断言任务物理不可达。
