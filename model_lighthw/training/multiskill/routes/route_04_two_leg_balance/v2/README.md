## 正式训练

完成本目录`validation/README.md`列出的检查后，在仓库执行：

```bash
cd /home/user/RL_lab/rl_training
bash model_lighthw/training/multiskill/routes/route_04_two_leg_balance/v2/scripts/r4_v2.sh train \
  --num_envs 512 \
  --max_iterations 1000 \
  --eval_every 100 \
  --seed 42
```

默认使用本机`lab`环境，从零初始化v2 Actor/Critic；正式命令由用户执行。每100轮独立冻结前/后×seed43/44/45复评，之后接续模型、Adam、LR与RNG。输出为`v2/runs/<时间戳>/`，终端打印`[R4 V2 REVIEW DIRECTORY]`。不自动加载短验模型或v1模型，不自动增加预算或晋级。

`max_iterations`为优化尝试数；正常更新保留，整批KL超过0.03的尝试回退模型和Adam、减半LR（下限1e-6），并在`updates.jsonl`记录`accepted=false`。因此1000次尝试不保证1000次保留更新。每32步rollout，512环境的1000次尝试仍采集16,384,000个环境转移。`completed_updates`沿用计数名称，v2含义为已完成尝试数，验收必须另看`accepted`和真实行为。

段末若至少128个已结束训练回合全部`entered=false`，入口报错停止，避免继续空跑；训练完成状态不是行为合格。冻结无成功不会自动延长训练。没有自动选择可部署模型。

## 入场、阶段与探索

- 出生后0.2秒保持原零动作安放；之后Actor自主输出腿位置/轮速度目标，没有外力扶持、预设抬腿轨迹或根状态运动注入。
- 初始站稳、双腿保持、返回后站稳三个静止阶段的高斯动作std为学习std的0.03倍；转移和返回运动阶段使用完整std。Actor均值保持不缩放；PPO的采样、概率密度、熵、KL都使用相同的条件高斯分布，不在环境端再缩放采样噪声。
- 初始站稳仍需真实1kHz连续0.5秒：四轮各>5N，COM速度≤0.12m/s，角速度≤0.25rad/s，倾角≤12°，根高0.416±0.07m。最早1秒开始转移；未达到则继续等待，3秒仍未入场以reason=5终止。
- 从实际入场启动时刻起：转移3秒→双腿窗口3秒（要求连续2秒）→返回3秒→恢复2秒。常规完整回合12秒，延迟入场时最长14秒；超时由事件时钟决定，不因等待压缩保持/返回时间。
- 305维Actor、88维Critic、16维动作保持；Actor仍仅使用IMU/编码器/上一动作、模式、目标重力、阶段和绝对回合时间。事件阶段由环境真实验收状态推进，接触/COM真值不直接加入Actor向量；实机阶段切换的接触与速度估计尚未验证。
- 新增`entry_best`、`start_time`、入场四轮/线速度/角速度/姿态逐条件计数及`best_pair`诊断，区分入口未激活与双支撑本体未学成。

## 奖励变化

连续项仍乘实际控制dt=0.02，事件项单次计奖。

| 项目 | v2设置 | 目的 |
|---|---|---|
| 姿态 | 权重4，指数宽度0.9rad | 从水平站姿到约±55°目标有可见的连续引导 |
| COM距指定有限轮轴线 | 权重4，指数宽度0.35m | 在原约0.35m误差处仍有递增信号 |
| 转移支撑 | 权重3，承载×另一对卸载进度 | 均匀四轮承重收益为0，腾空收益为0 |
| 初始/返回四轮支撑 | 使用上述支撑项的0.25系数 | 减少四轮停留的总收益 |
| 悬空净空 | 权重2，8cm饱和 | 奖励真实指定两轮支撑下另一对抬起 |
| 初始安静站稳 | 权重2 | 为入场站稳提供直接学习信号 |
| 漂移 | 保持/恢复使用各窗口起点、10cm自由区；其他阶段保留60cm | 避免把全回合60cm门当保持门 |
| 严格保持/恢复/首次保持/终末成功 | 6/4/10/20，原条件 | 以真实连续完成决定核心收益 |

承载系数取两支撑轮较小轮载相对四分之一体重的比例，限制到[0,1]，并要求轮部总载荷≥0.65倍体重。卸载进度为`clip(1 - 另一对轮载合计/(0.5mg),0,1)`；不会因四轮同时腾空获得支撑收益。

动作平滑、力矩/关节速度/轮速/动作边界、真实失败等项保留。学习率从1e-4开始，采用整批KL回退后的减半规则；初始腿std0.2、轮std0.08，学习std限制0.03–0.6，静止阶段条件缩放在此基础上施加。Gaussian原始动作仍由环境裁剪[-1,1]，日志应继续检查裁剪比例；不宣称策略本身无界输出已消除。

## 保持的物理与完整成功条件

规范URDF、质量11.668111kg、腿/轮48/24Nm、速度12.57/37.7rad/s、腿PD80/3、轮速目标±15rad/s、μ=1、自碰撞、陀螺力、刚体角速度保护100000deg/s、solver8/2及1kHz物理/50Hz策略均保持。Actor腿目标的STAND/LOW/HIGH分段线性映射保持。

完整成功要求真实初始站稳后：指定两轮各>5N，另一对各<2N且净空≥3cm，COM距支撑线≤6cm，COM速度≤0.12m/s、角速度≤0.25rad/s、目标姿态误差≤12°、窗口漂移≤10cm，连续保持≥2秒；随后在终末四轮站稳连续≥1秒。中断按1ms清零，早先站稳但终末失稳仍失败。非轮碰撞、跌倒、越界、非有限状态及新增入场超时均不作为成功。

晋级仍要求最终模型前后各至少20例、跨至少3seed、各≥95%完整成功，并审查动作/力矩、姿态/速度/接触/漂移；默认每轮6例用于筛查。本次软件/入场短验不代表双腿保持收敛或实机验收。
