## 目标与验收口径

R4a从固定四轮初态起身，以两后轮支撑；站立指令持续有效时持续调节平衡，没有自动返回时刻。只有外部明确发出返回指令才转回四轮。R4b继续等待，保持原机器人、执行器和动作映射，关闭观测噪声、初态及域随机化。

- 连续2秒合格只记为“完成捕获”里程碑，不结束回合、不发完成大奖，也不代表PPO准入或持续站立通过。
- 捕获锁存后开始长保持计时，10/30/60/300秒均指**捕获后的额外连续合格时间**。不把起身时间或前面的2秒计入这些时长。
- 捕获后第一次姿态、支撑、速度或实际振动越限，立即记录中断时刻及原因，本次完整长保持判失败；后续重新站稳单独记录，不能用后来最好的一段覆盖首次中断。训练可以继续学习恢复，但通过标记不能复活。
- 测试到时只说明观察结束，单列`truncated`及“完成本次规定观察时长”；不把timeout本身当成功、倒地或返回指令。测试截止时间不输入策略。
- 最终验收要求60秒重复自主保持，再做300秒自主耐久检查，并检查末段没有失稳、加速漂移或振动恶化。有限测试只能证明对应时长，功能设计则不设站立到期时间。

保留当前稳定门：两后轮各>5N、两前轮各<2N且净空≥3cm、COM投影距后轮有限支撑线段≤6cm、目标姿态误差≤12°、COM总速度≤0.12m/s、机身角速度≤0.25rad/s。慢漂移允许累计，不能恢复10cm原点门。

实际抖动继续按1kHz物理状态检测：二阶Butterworth高通截止5Hz、指数RMS时间常数0.10秒；COM速度/机身角速度/最差腿关节位置/最差轮速度RMS上限分别0.02m/s、0.05rad/s、0.2°、0.50rad/s。捕获后全程检查，不用动作平滑替代实际状态检查，不在中途重置滤波器。

## 奖励调整设计

下表已在独立v7实现，原v6参数保留。连续项沿用初始量级；合成奖励审计、真实GPU分项与本轮37次PPO准入短验已完成，正式长训练效果仍待审查。

| 奖励/成本 | 首版计划 |
|---|---|
| 合格平衡，当前权重12 | 保留12；改为累加一个20ms控制周期内20个1ms物理样本的合格时间，`12 × Σ(0.001 × stable)`，整个站立指令期间持续生效 |
| 姿态、COM、后轮承载、前轮卸载/净空、捕获质量 | 初始沿用v6连续权重与承载门；起身提供方向，站稳后仍依实际质量给分；四轮停留、跳起或前轮重新落地不能取得完整站立收益 |
| `hold_once=20`、`success_once=40` | 持续站立任务中设为0；2秒里程碑和观察结束仅记录指标 |
| 原7秒`missed_hold=-8` | 移除定时返回触发的扣分，改为明确的入场/起身失败判定；首版从真实入场/开始起身事件起计8秒仍未完成捕获时结束该失败回合，独立记录，不能无限停在四轮赚辅助收益 |
| 返回姿态、返回四轮恢复 | 仅外部返回命令有效时激活；保持期间即便曾经站稳，也不能因主动落回四轮获得这些收益 |
| 通用时间成本`-0.1 × dt` | 保持阶段关闭；仅起身阶段保留该成本 |
| 原点漂移成本`-1` | 取消；速度超过0.12m/s的成本仍保留，允许慢速累计位移 |
| 实际抖动、超速、动作一阶/二阶差分 | 保留v6初始权重−0.5/−2/−0.05/−0.25，保持阶段全程生效，检测器不能在达成里程碑后停止 |
| 力矩、关节速度、轮速度、饱和和失败 | 保留原初始量级；失败只结算一次，不用夸大的完成大奖补偿中途失稳 |

连续项均按物理/控制时间积分，避免控制频率改变收益。每一秒合格站立获得同样的基本收益，不额外按累计保持时长放大奖励，也不在每次重新捕获时重复发奖。一次捕获后再失稳，当前稳定收益立即下降，不能依赖旧`held`标记继续计满分。

奖励审计必须比较持续站立、四轮停留、捕获后主动倒回、重复起落、缓慢漂移与高频抖动的逐项及折扣收益。长回合总分天然更大，报告同时给每秒收益和行为时长；采样/BC训练按起身、捕获、保持分组，避免大量静态保持帧淹没起身数据。平稳教师动作仍需基于学生实际访问状态闭环纠偏，不能只复制一帧姿态。

## PPO与迁移约束

现有305维输入包含时间语义。即使新版本通过替换通道仍保持305维，也不能按维度相同直接恢复第四轮checkpoint；应冻结新观测合同，显式记录旧Actor迁移或重新BC，Critic和PPO优化器重新初始化。旧的短时返回数据单独标记，只用于对应阶段或返回命令，不混入“站立指令持续有效”的保持标签。

若仍用第四轮Actor前3.2秒状态做接管对照，需要独立的旧观测适配器给旧Actor，并另外记录新策略观测；不能把改过语义的输入直接送给旧Actor，声称前缀可比。不改原执行文件和已存轨迹。

本机Isaac Lab的RSL wrapper只有在`is_finite_horizon=False`时传递`time_outs`；当前安装的RSL PPO用`transition.values`做timeout奖励修正。因此仅翻转配置开关还不足以宣称截断处理正确。新链路需用受控数值检查：物理失败不续接价值；时间截断使用重置前末状态价值、不误用重置后状态、不重复修正；rollout批次结束能够连续采样并正确计算优势。按所安装版本做独立适配，不修改全局依赖来影响其他路线。

当前`gamma=0.995`在50Hz下的折扣特征尺度约4秒，不能据此断言无法长期站立。首轮需审计持续任务的Critic目标、奖励量级和GAE/rollout长度，再决定是否单独对照更长折扣；不能仅调gamma就宣称学会持续稳定。采样批次结束、checkpoint保存均不得触发起身/返回或重置正在站立的环境。
