## 当前物理与能力边界

当前训练候选保持实际验证过的 μ3、GPU 16/4、40 kg 无动力拖车、原机器人质量/惯量、80/3 腿伺服、96/48 Nm 限矩、k2000/c150 牵引杆和普通零速初态。没有观测噪声、环境随机化、在线教师或 reset 后状态修正。PPO 采样动作仍用于探索；它不等于环境观测噪声。

μ3 下已有普通初态上下坡完整教师，但学生尚未自主完成。两向精确开环动作重放也未完成，不能把原轨迹称为可靠自主初值。μ4 已实测：它有利于部分空载对照，却未解决当前教师的重拖入场；k500/c75 柔顺杆的两项对照也失败。这些独立物理候选没有混入本入口的物理配置或通过证据。

完整目标仍是普通进入、机器人和拖车净行进至少 1 m、滚动主导、减速、2 s 过渡与 5 s 保持，同时保留空载高速及 15 kg 背载能力，特别覆盖 −20°/40 kg 下坡制动。最终阈值不变，部分轮接触仍许可。源有效、loss 降低、训练运行完成或任务时钟走完，都不代表这些行为已通过。

## 正式启动命令（由用户执行）

以下配置已通过实际短验及正式入口 CPU 预检。初始化明确为未通过自主验收的 BC 候选，正式训练从上述短验的 2 次接受更新继续。旧 V6/V8、旧 300 维学生与其他路线 checkpoint 不可直接作为本入口续训来源。

```bash
source /home/user/miniconda3/etc/profile.d/conda.sh
conda activate lab
export TERM=xterm OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
cd /home/user/RL_lab/rl_training/model_lighthw/training/multiskill/routes/route_01_wheel_locomotion/research_v7

python -u exploration_v1/train.py train \
  --validated-short-run results/2026-10-23_admission_continuation/exploration_short512_batch_gpu \
  --output results/2026-10-23_exploration_ppo_formal \
  --num-envs 512 --inference-mode batch \
  --towing-initialization bc_preparation_9f406 \
  --iterations 10000 --save-interval 100
```

`--iterations 10000` 是**追加 10000 次 PPO 提案**，包含 KL 拒绝的提案；实际接受数单列。每 100 次保存一次，保存不会终止训练；没有旧 200/600 轮行为不达标早停。NaN、源变更、恢复或保护检查失败仍会明确报错。输出目录须为新目录，当前正式输出目录尚未创建。

源码、环境数、推理方式或初始化变化后需要新的对应短验；不能修改证据里的哈希绕过验证。正式续训可在上述命令中另加 `--resume-checkpoint /先前正式目录/proposal_XXXXXX.pt`，并改用新的 `--output`；恢复模型/Adam/RNG，物理环境从普通初态重新开始。具体计数和源绑定见 [执行接口](RUNTIME_INTERFACE.md)。

正式运行输出 `updates.jsonl`、`proposal_XXXXXX.pt` 与结束时的 `final.pt`。后续按冻结 Actor 独立验收两向重拖、1 m、滚动、减速、2+5 s保持及空载/背载能力；训练在线奖励与任务阶段计数不能替代该验收。
