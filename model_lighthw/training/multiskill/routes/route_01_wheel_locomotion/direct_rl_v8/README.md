# R1 V8：直接 PPO 搜索统一轮足策略

**2026-10-20固定条件版本已完成训练入口验证，可以启动正式PPO。完整重拖行为尚未验收。** 第一阶段关闭观测噪声及额外随机化，先学习固定条件目标；保留PPO动作分布的必要探索。本线由用户于2026-10-20授权，接替V7作为下一次RL训练方向。WBC/QP保留为物理诊断，不是训练前置条件。训练入口准入与行为成功分开记录，长训练由用户启动。

## 目标与接口

一个部署Actor完成空载高速、15 kg背载和40 kg被动拖车；首批训练覆盖全部64许可工况。+25°重拖和−20°重拖制动均包含，−25°仍排除拖车。Actor300→512→256→128→16；前动作历史80列继续屏蔽；原生12腿位置＋4轮速度、50 Hz控制、1 kHz物理。Critic扩展为268维，新增拖车速度/净进度、拖杆状态、四轮载荷和保持统计，全部只在训练使用。

μs=μd=3.0、滚阻.02、96/48 Nm、刚体及关节速度上限、真实双向弹性拖杆沿用已审计设置。姿态仍允许主动调整，不设教师接管或瞬时接触守卫。真实碰撞、翻覆和5 mm牵引净高终止保持。

在项目根目录执行以下命令，正式长训练由用户启动：

```bash
cd /home/user/RL_lab/rl_training
source /home/user/miniconda3/etc/profile.d/conda.sh
conda activate lab
export TERM=xterm
python model_lighthw/training/multiskill/routes/route_01_wheel_locomotion/direct_rl_v8/scripts/train.py \
  --headless --num_envs 512 --max_iterations 3000 --eval_interval 100
```

该命令从已验证的旧能力初始化Actor开始，先20次Critic预热再联合PPO；不加载本轮短验模型。预算共3000次更新。启动时及每100次做18边界冻结复评，默认种子43/44/45；准入短验仅用43，不能声称完成多种子鲁棒性验证。重复退化保护可能提前停止，没有600次硬停止。

固定初态、固定μ/质量/坡度集合；移动指令固定为空载3.1 m/s、背载/拖载.3 m/s。训练默认关闭policy观测扰动；随机高斯只用于PPO采样动作，部署与冻结验收使用确定性均值。鲁棒性阶段待行为达标后另行启用。

## 输出与停止条件

runs/下为每次新建目录，保存请求、环境/网络契约、资产/源码SHA、训练日志、冻结轨迹和checkpoint。training/condition_optimizer_metrics.csv用于检查困难工况是否真正参与更新；condition_metrics.csv区分协议完成事件和行为成功。每100更新评估旧能力保护，未必跑满预算；没有固定600轮停止。

quality/best_eligible.pt只表示保住受保护边界，exported/actor.pt也不代表R1全工况验收。完整验收包括18边界、128工况和独立噪声/初态扰动；最后才进入持续电机负荷/硬件研究。使用--resume恢复模型、Adam、PPO计数和RNG，但不恢复PhysX场景状态；重置后继续收集新的on-policy数据。


## 实施顺序与判定

1. **已完成：固定物理和更新链路。** 对齐评估创建模板，保持原生控制/力矩和μ3；验证64工况首批覆盖、单Actor接口、真实拖车进度、完整起停奖励、PPO更新和恢复。
2. **当前：直接RL学习。** 正式运行上述命令。重点读取困难上/下坡各阶段的有效样本、优势、KL，以及冻结轨迹中的姿态、四轮支撑、牵引净高和两车进度；奖励上涨或轮数完成不等于目标实现。WBC保留为诊断工具，无教师接管。
3. **后续：固定条件完整验收。** 保住已有15边界，新增+25°40kg移动、−20°40kg静止/制动全部通过，再评估128个全条件起停组合。要求真实1m拖行＋减速＋实际零指令后2s过渡＋5s保持，原姿态/支撑/漂移/碰撞标准不放宽。
4. **行为达标后：鲁棒性与硬件。** 再逐项加入观测噪声、初态和物理参数扰动，检查退化；持续负荷和硬件选型使用完整行为轨迹研究。
