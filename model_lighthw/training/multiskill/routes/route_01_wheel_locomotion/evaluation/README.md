# Stage1 确定性筛查

协议来源：`multiskill/protocol.py`，版本`lighthw_multiskill_stage1_screen_v1`。
训练seed42；评估默认43/44/45。固定初态、干净观测、无随机推力，平地、载荷0kg、牵引0N。

每case18秒：0～3秒零，3～11秒目标速度，11～18秒零。目标依次0/.3/.6m/s；
5～11秒计算跟踪，13～18秒计算停后保持。启动瞬态保留在CSV，不混入巡航均值。
退出/NaN/Inf/环境提前终止算不完整失败，不读取重置出生帧冒充保持。

候选筛查门槛：巡航平面速度误差均值≤.12m/s、全程倾角P95≤10°、
保持平速均值≤.03m/s/偏航角速均值≤.05rad/s、保持四轮同时>5N比例≥95%、
平均动作目标裁剪比例≤20%、无非轮碰撞，且全程完整。移动不设四轮持续接地否决。
完整case通过率独立输出；95%课程目标是后续多次reset的候选门槛，不自动升级。

CSV保存实际/目标速度、姿态、位置/漂移、每轮垂向接触力、每关节力矩与目标/裁剪，
JSON记录失败、跌倒/超时、成功、seed和实际工况。采样50Hz，峰值必须标为50Hz观测值，
不能声称捕获1kHz接触/力矩瞬态。附加载荷为0，实际总质量另存runtime_check。
固定reset会使不同seed轨迹相同；真实鲁棒性仍需设计初态/摩擦/载荷扰动矩阵。

`final_acceptance=not_evaluated`始终保留：这一协议不验收3m/s、25°、15kg、40kg牵引。
