# R5A v6 技术路线

依据2026-10-22返回的v5/1201冻结轨迹：147.005°后旋、19.165cm离地后COM增高、0.370s滞空；角动量漂移1.54%，通过既定筛查，但单圈/站稳未通过。0.4s开放策略，0.468s离地，主动COM预蹲为0。0.469–0.537s短暂减小惯量，0.498s最低比离地降低13.26%；有效腾空到0.569s才确认，旧收腿奖励因此为0。

## 1. 收腿信用与真实动作时刻对应

在1kHz状态机中，以初始横轴的后旋角度计算每次**单调新增**的单圈进度（上限1），乘以同一物理帧的紧凑度：

`clip((1 - I_locked / I_release) / 0.20, 0, 1)`。

积分暂存为`compact_credit`。7帧离地确认前使用候选释放惯量暂存，确认时转入正式累计量，因此不会丢失最早的6ms。达到原有效腾空条件（至少0.10s、增高0.02m）后才释放为`compact_potential`，每20ms仅支付其新增部分。早期收腿可以在确认后获得信用；短跳不兑现；前翻、反复摆动、首次触地后的再次起跳不重复获得旋转信用。单次潜在紧凑奖励上限8，不能无限刷分。

0.20是紧凑度归一尺度，不是强制收腿角度、参考轨迹或必须达到的物理目标。保留1kHz原始惯量、动作、接触、累计信用以及在线状态，便于下一次独立复算。训练与回放均使用同一规则，验收与奖励分开。

## 2. 让地面Actor有机会改变快速蹬伸模式

初始化来源为用户返回的v5 `selected.pt`，源SHA256：
`845fb32576ca57fcdf60a6b5899ebf2e04bfde3682cf0b02a3d4bcd6b20456c9`。

两个Actor及`log_std`先完整迁移；空中/恢复分支逐张量不变。地面分支隐藏层不变，只将最后一层权重、偏置都乘0.35，使初始地面目标更靠近站姿。地面腿探索标准差下限由0.20提高为0.30，轮仍0.10；保持同一个tanh-Normal采样、log_prob、熵与KL计算，没有额外注入环境/传感器噪声或不入概率模型的动作扰动。

这会主动改变v6的地面确定性输出，**不能声称整条v5起跳轨迹原样保留**。它是基于原Actor特征的准备动作探索起点，不是已证明更好的姿态控制器。35%与0.30是本轮研究参数，需新GPU训练检验，不宣称最优；没有预先规定下蹲角度、起跳时刻或强制准备时长。

Critic与Adam重新创建，v6计数从0开始；不加载旧v5优化器。观测/动作维度、频率和物理保持，所以能明确复核迁移前后的Actor输出。v5源文件和检查点保持。

## 3. 奖励分配调整

| 项目 | v5 | v6 | 目的 |
| --- | ---: | ---: | --- |
| 高度 / 滞空 | 3 / 1 | 1.5 / 0.5 | 保留真实腾空信用，降低只延长飞行的收益 |
| 联合高度-时间-转角进度 | 16 | 12 | 减少仅靠高度提高同转角评分 |
| 独立空中转角进度 | 10 | 16 | 增强首次飞行新增转角反馈 |
| 紧凑旋转 | 2，瞬时门控 | 8，历史积分且验证后兑现 | 信用与早期收腿对应，并校准量级 |
| 准备 / 蹬伸势塑形 / 准备成果 | 2 / 2 / 2 | 4 / 4 / 4 | 为真正压缩—蹬伸提供更强但有界的反馈 |
| 起跳协调 | 4 | 3 | 减少只优化起跳代理量 |
| 首次触地转角 / 姿态 | 3 / 4 | 4 / 6 | 强化首次着地前的完整动作质量 |
| 首次触地剩余转角代价 | −2 | −5 | 加大未完成旋转就接触的缺口代价 |

起跳H分量从`clip(H/2.6,0,1)`改成`max(H,0)/(max(H,0)+2.6)`，仍有界，但在旧v3的2.6量级不再硬截顶。2.6只是归一尺度，不是必需H。仍要求正垂向能力及正确机身转向，不注入根速度/外力，也不把多体系统错误当作固定惯量刚体。

准备势塑形仍用`gamma*Phi(next)-Phi(now)`，终末势归零；成果分仍绑定近期真实压缩后的带正垂速蹬伸、再达到有效腾空。单纯站着、下蹲不跳或反复蹲不产生无限收益。具体可探索性尚需GPU验证。若能直接蹬伸完成合格空翻，成功判定不会因没有预蹲而拒绝。

不使用固定收腿/伸腿参考动作序列。新反馈主要奖励实际旋转、紧凑动作和首次触地姿态；不规定一个固定根角速度目标，不把提高跳跃高度当作唯一方向。

## 保持的边界与工作流

420/104/16维度，1ms物理/20ms策略，6s回合；腿48Nm/12.57rad/s、轮24Nm/37.7rad/s，PD、质量/惯量、摩擦、自碰撞、重力、求解器与armature均保持。无初态/物理随机化、无观测噪声。350–385°、首次触地≤20°、轴向偏差≤20°与终末1s站稳要求不变；H筛查仍为原5%/0.02门。

默认512环境连续3000更新；中途每200只存档；末尾一次评估最后最多3候选、一个模型精简回收。增加`Ended/angle_deg`、`Ended/preparation_cm`、`Ended/compact_credit`、`Ended/release_H`便于解释训练趋势。修正中断会话更新数以及单模型评估包的范围标签。

本版不是物理可行性证明。实际新策略效果、准备探索是否成功、动作切换H残差与落地稳定性必须由下一份USB物理轨迹确认。CPU测试/历史奖励重放/安装检查与新GPU行为验收明确分开。
